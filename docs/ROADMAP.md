# 开发路线图（ROADMAP）

> 本文档记录项目未来的功能规划与灵感，按优先级和时间线组织。
> 灵感转瞬即逝，先记下来，做不做是以后的事。
> 已完成的功能见 [CHANGELOG.md](../CHANGELOG.md) 与 [README.md](../README.md)。
> ⭐ = 优先级较高 / 已明确方向；💡 = 纯灵感 / 待评估

---

## 一、近期规划（V1.1 ~ V1.2）

### 1. V1.1 工程化拆分 ⭐⭐⭐
- 当前 V1.0 为单文件 JS（`js/account.js`），随着功能增多已较臃肿
- 计划拆分为：工具函数层、存储封装层、数据访问层、业务模块层、组装层
- 测试用例纳入 `tests/account/`，数据相关改动一律先跑测试
- 为引入账单模块打基础；存储 key 保持不变，纯搬家

### 2. 账单模块 ⭐⭐⭐
- 账单记录（IndexedDB 存储，高频，一天可能多条）
- 分类管理（一级分类 + 二级子分类），分类全自定义、不写死预设
- 平台管理、标签管理
- 高级筛选（年份/金额区间/标题/日期/类型/分类/平台/备注/标签）
- 分页、排序

### 3. 目标新增计算维度：当前存款能撑多久 ⭐
- 目标页增加计算维度：当前存款按当前每月消费水平能撑多长时间（类似 FIRE 运动的 runway 计算）
- 输入每月消费，算出现有存款可支撑的月数

### 4. 详情页加「本次统计周期」⭐
- 查看详情备注上方加一行：`本次统计周期：2026.06.23-2026.07.11`
- 记录本周期的大额收入和支出
- 与账单联动：可查看该周期内的账单明细

### 5. 数据自检 / 修复工具 ⭐
- 启动时校验银行卡 key 与记录字段一致性
- 缺失字段补默认值、识别脏数据

### 6. 导入 JSON 健壮性校验 ⭐⭐
- 导入时校验 JSON 中 config 字段是否存在、格式合法，防异常数据崩溃
- 加载配置时增加数组类型和长度判断，防 localStorage 数据异常白屏

## 二、中期规划（V1.2 ~ V2.0）

### 1. Summary 汇总耦合到账单 ⭐⭐⭐
- 汇总区域展开/收起，位置在操作栏下方、筛选栏上方
- 默认收起，点二级分类时筛选下方列表
- 汇总区限高 + 内部滚动

### 2. 账单图片展示 ⭐⭐
- 上传手机相册图片，`<img>` 显示
- 详情页多图显示（平铺 / 左右滑动 / 九宫格缩略图）
- 点击看大图，再点缩小

### 3. 账户统计与账单数据互通 ⭐
- 账户详情页可查看当前统计周期内的账单
- 账户继续用 LocalStorage，账单用 IndexedDB，两页数据通过统计周期关联

### 4. 主题切换 ⭐
- 用户可自由切换视觉风格（纤细/浑厚字体、不同配色）

### 5. 导出 xlsx 格式 ⭐
- CSV 不支持颜色、合并单元格、公式等格式设置
- 导出 xlsx，让定期导出的报表更美观

### 6. 操作撤销 ⭐
- 删除记录/银行卡后 toast 内出现「撤销」

## 三、长期愿景（V2.0+）

### 1. 图表统计（V2.x 招牌功能）⭐⭐
- 存款增长曲线
- 目标达成进度
- 月度对比
- 数据现成、成本不高、视觉冲击力强

### 2. 年度账户总结视图 ⭐
- 今年存款增长曲线、目标达成进度、月度对比
- 作为 V2.x 招牌功能

### 3. 后端服务（Java / Go / PHP + MySQL）⭐⭐
- 分别用 Java / Go / PHP 实现后端存储，数据存 MySQL
- 前后端放同一个仓库
- 数据访问层直接换 HTTP 调用，业务层不动

### 4. 多端延伸 ⭐⭐
- 小程序、APP
- HTML 套壳 apk 安卓应用
- iOS 应用

### 5. 数据版本兼容升级工具 ⭐⭐⭐
- 每次打开检测旧版本字段名，自动升级数据结构
- 尽量完美兼容旧版本（已有用户使用的数据）

### 6. 历史导出对比报表 ⭐
- 导入历史 JSON/CSV → 自动生成两次统计之间的变化报表（存款增减、目标进度推移）
- 正好用上定期导出的历史文件

### 7. 手机端应用锁 💡
- 简单 PIN 锁，保护手机上的个人财务数据

## 四、灵感池（待评估）

- **瀑布流菜单**：按钮太多时，点一下出来一个瀑布流（类似手机 APP 菜单按钮样式）
- **个人设置**：可设置页面上显示哪些按钮、是否放开「清空数据」「彻底删除银行卡」
- **多语言**：是否做多语言支持（i18n）？（个人工具，优先级低）
- **操作记录日志**：记录每次数据变更（增删改），方便回溯
- **轻量账单**：只记录日期、标题、类型、金额，共 3 行，快速录入
- **本地服务器方案**：`python3 -m http.server` 可跑，但和静态访问 HTML 数据不互通
- **添加数据后自动备份**：每次添加/修改数据后自动生成备份
- **银行卡更多操作选项**：参考市面 APP，考虑长按菜单、滑动操作等
- **首页 vs 列表**：目前无独立首页，打开即列表；未来是否做概览首页
- **分页页码按钮**：已支持输入页码跳转，可再补一组数字页码按钮
