# 家庭账户统计

一个运行在浏览器本地的**家庭账户统计**小工具：不定期记录家庭各账户的存款 / 负债余额，查看账户变化趋势与目标达成进度。

> 定位：这不是"账单记账"，而是"**账户统计**"——每月记录一两次，记录的是各银行账户的余额快照，用于观察家庭总资产的变化。

## 功能特性

### 账户统计

- **银行卡配置管理**：新增、编辑银行卡，自定义显示名称与类型（存款 / 负债 / 两者兼备）；支持禁用 / 启用
- **账户记录增删改查**：添加、编辑、删除记录；同一天不能重复录入；默认填充今日日期
- **查看 / 编辑态分离**：点击日期打开记录弹窗默认只读，点击「编辑」才可修改；查看态展示「总余额」「汇总」信息及余额计算公式，日期以点分格式置顶显示
- **复制记录**：查看记录时可快速复制新增，金额数据全部保留、日期自动设为今天
- **弹窗未保存关闭确认 + 编辑态刷新拦截**：编辑状态下刷新或关闭弹窗会弹出确认，防止未保存输入丢失
- **金额展示**：千分位格式化；总余额按正负分色；存款 / 负债分别用不同颜色标识
- **对比差额列**：列表展示每条记录相对上一次统计的总余额变化，负数橙色 / 非负灰色
- **存款 / 负债并排显示**：列表与弹窗中同一张卡的存款、负债改为一行并排

### 目标计划（智能计算）

- 设定**年收入、每年计划费用、目标日期**及说明
- **目标金额自动计算**：年费用 ÷ 12 × 剩余月数，不再手动填写目标金额
- **预计达成日期估算**：按年收入水平自动推算预计达成日期，展示完整计算过程公式
- **每月最低收入测算**：结果区分两段展示——「距离目标剩余金额和截止日期」「每月最低收入」，倒推每月 / 每年所需的最低收入金额
- **旧版数据兼容**：检测到旧版目标数据时橙色提示引导补充，并折算每年计划费用参考值
- 目标支持查看 / 编辑态切换，编辑时「返回」会先确认未保存修改

### 数据能力

- **导入 / 导出JSON**：一键导出完整数据（银行卡配置 + 账户记录 + 目标计划）为 JSON 文件，文件名带日期；支持导入
- **合并导入**：导入拆分为「覆盖导入 / 合并导入」，合并导入按日期去重、增量补充已有数据
- **导出CSV表格**：账户记录导出为 CSV 文件，头部含目标计划部分（年收入、目标金额、当前总余额、剩余金额、预计达成日期、剩余时间），含对比差额列
- **刷新 / 清除数据**：「刷新」按钮免刷新重载；「清除数据」带二次确认
- **Mock 示例数据**：内置 `html_single/account_mock.json` 示例数据，可一键导入快速预览完整功能
- **移动端适配**：窄屏下表格、弹窗、分页控件自动收敛，手机浏览友好

## 快速开始

1. 直接用浏览器打开 `html/account.html`（支持 `file://` 协议，无需启动服务器）
2. 首次使用：先添加银行卡，再添加账户记录；也可以直接导入 `html_single/account_mock.json` 体验完整效果
3. 如果手机浏览器不支持 `file://` 协议，建议使用 `html_single/account.html` 单文件版（支持 `content://` 协议）
4. 数据保存在浏览器 **LocalStorage** 中，建议定期**导出JSON**备份

## 数据说明

- 存储于浏览器 LocalStorage，key 以 `financial_account_` 为前缀：
  - `financial_account_records`：账户记录
  - `financial_account_bank_card_configs`：银行卡配置
  - `financial_account_target`：目标计划
- 导出 JSON 包含 `version` 与 `exportTime` 元信息，便于数据溯源
- 纯本地数据，不上传任何服务器

## 数据安全与备份

- 所有数据仅保存在你的浏览器 LocalStorage 中
- **清除浏览器数据会导致数据丢失**，请定期导出 JSON 备份
- 建议每次重要记录后导出一次 JSON 文件保存
- 换电脑/浏览器时：在旧浏览器导出 JSON，在新浏览器导入 JSON

## 常见问题

**Q：换了电脑/浏览器，数据还在吗？**
A：不在。数据存在当前浏览器的 LocalStorage 中。请在旧浏览器导出 JSON，在新浏览器导入 JSON。

**Q：数据会上传到服务器吗？**
A：不会。本项目是纯前端工具，所有数据仅保存在本地浏览器中。

**Q：清除浏览器缓存会丢数据吗？**
A：会。清除浏览器数据/缓存会清空 LocalStorage，请务必先导出 JSON 备份。
